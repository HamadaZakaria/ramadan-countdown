# Ramadan Countdown 1448 هـ

صفحة عربية ثابتة تفاعلية لعداد رمضان، تعمل بملفات HTML وCSS وJavaScript دون إطار عمل أو خطوة بناء.

## المحتويات

- `index.html` — الواجهة العربية وبيانات الصفحة الوصفية.
- `styles.css` — التصميم المتجاوب والحركات.
- `app.js` — العدّ التنازلي والتحكم اليدوي بالصوت والحركة.
- `ramadan-logo.svg` — الأيقونة.
- `assets/ramadan-night-loop.mp3` — مقطوعة قصيرة مضمّنة مع نسبها إلى LemonMusicLab عبر Pixabay في الصفحة.
- `.github/workflows/pages.yml` — نشر تلقائي بواسطة GitHub Actions عند التحديث على `main`.

## النشر

في إعدادات المستودع، افتح **Settings → Pages** واجعل مصدر البناء **GitHub Actions**. بعد ذلك ينشر الـ workflow الموقع من جذر المستودع. لا يحتوي هذا المستودع على إعداد نطاق مخصص؛ يُضاف بعد تحديد النطاق المطلوب.

موعد بداية رمضان المعروض تقديري، وقد يختلف يومًا بحسب رؤية الهلال والإعلان الرسمي في بلد المستخدم.
