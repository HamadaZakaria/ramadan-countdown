# Ramadan Countdown 1448 هـ

المستودع العام لملفات المصدر الخاصة بصفحة عدّاد رمضان العربية التفاعلية. يحتوي الموقع على واجهة HTML وCSS وJavaScript متجاوبة، وشعار SVG، ومقطوعة قصيرة منسوبة إلى LemonMusicLab عبر Pixabay.

## الملفات

- `index.html` — الواجهة العربية وبيانات الصفحة الوصفية.
- `styles.css` — التصميم المتجاوب والحركات.
- `app.js` — العدّ التنازلي والتحكم اليدوي بالصوت والحركة.
- `ramadan-logo.svg` — الأيقونة.
- `assets/ramadan-night-loop.mp3` — المقطوعة الصوتية، مع الإسناد داخل الصفحة.

## حالة النشر

هذا المستودع يحتفظ بملفات المصدر العامة فقط؛ لا يوجد حاليًا نشر فعّال للموقع على GitHub Pages ولا نطاق مخصص. موعد رمضان المعروض تقديري وقد يختلف بحسب رؤية الهلال والإعلان الرسمي.
